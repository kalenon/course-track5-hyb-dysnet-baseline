# 《语音信号处理》大作业赛题 5：语音构音障碍严重程度评估

## 1. 任务定义

肌萎缩侧索硬化症 (Amyotrophic Lateral Sclerosis, ALS)是一种常见的神经退行性疾病，典型的症状是肌肉无力、萎缩、动作僵硬，进而造成构音障碍，影响患者的语音功能。
构音障碍会影响发声的稳定性、音质、发音速度、音节节律及元音共振结构。对这些语音变化进行自动、客观的量化分析，有助于探索非侵入式的语音健康诊断方法。本赛题要求构建受试者级的语音评估系统：根据一位受试者在评估时完成的多项发声任务，预测其构音障碍严重程度。

本任务仅用于语音信号处理课程中的算法比较与教学研究，不构成医疗诊断、治疗建议或临床决策依据。参赛系统不得被用于对真实个人作出医疗结论。

每名受试者对应八条单通道语音录音，系统必须综合全部有效录音，输出一个五分类结果。类别定义如下：

| 类别 | 含义 |
|---:|---|
| 1 | 重度构音障碍 |
| 2 | 中度构音障碍 |
| 3 | 轻度构音障碍 |
| 4 | 无构音障碍的患者语音 |
| 5 | 健康对照语音 |

任务描述：给定受试者 $i$ 的录音集合

$$
\mathcal{X}_i=
\{x_i^{(a)},x_i^{(e)},x_i^{(i)},x_i^{(o)},x_i^{(u)},
x_i^{(pa)},x_i^{(ta)},x_i^{(ka)}\},
$$

以及课程提供的基础元数据，系统输出一个类别

$$
\hat{c}_i\in\{1,2,3,4,5\}.
$$

其中，五条元音录音反映持续发声能力，三条快速重复音节录音反映构音节律与运动控制能力。参赛队可以采用时域、频域、时频域、自监督表征或多录音融合方法。

要求：在所提供的验证集上报告全部指标；生成盲测集的受试者级预测结果；提交推理代码、模型权重、结果样本，以及包含训练配置、验证指标、效率统计和主要创新点的技术报告。

| 项目 | 规定 |
|---|---|
| 输入 | 每位受试者 8 条单通道语音；WAV；8 kHz；16 bit |
| 输出 | 每位受试者 1 个类别标签，取值为 1--5 |
| 预测单位 | 受试者，而不是单条 WAV 文件 |

## 2. 数据构建与使用规则

### 2.1 课程提供的数据

课程将通过教学平台提供训练集、公开验证集、受试者清单及标签文件。训练、验证和隐藏测试集严格按受试者划分；同一受试者的八条录音只能出现在同一个划分中。

每位受试者包含以下八项录音任务：

| 录音组 | 文件夹名 | 内容 |
|---|---|---|
| 持续元音 | phonationA | 持续发 /a/，不少于 5 秒 |
| 持续元音 | phonationE | 持续发 /e/，不少于 5 秒 |
| 持续元音 | phonationI | 持续发 /i/，不少于 5 秒 |
| 持续元音 | phonationO | 持续发 /o/，不少于 5 秒 |
| 持续元音 | phonationU | 持续发 /u/，不少于 5 秒 |
| 快速音节 | rhythmPA | 单次呼吸内尽快重复 /pa/ |
| 快速音节 | rhythmTA | 单次呼吸内尽快重复 /ta/ |
| 快速音节 | rhythmKA | 单次呼吸内尽快重复 /ka/ |

音频文件名以受试者编号为前缀，例如：

~~~text
phonationA/S0023_phonationA.wav
rhythmTA/S0023_rhythmTA.wav
~~~

训练和公开验证清单包含以下字段：

| 字段 | 说明 | 是否可作为模型输入 |
|---|---|---|
| ID | 受试者编号，仅用于文件匹配 | 否 |
| Age | 年龄 | 是 |
| Sex | 性别编码 | 是 |
| Class | 构音障碍类别 | 仅训练、验证标签 |

## 4. 评分办法（100 分）

最终成绩同时考虑预测性能、模型效率和技术报告。不同指标量纲差异大，因此效率分项采用按名次换算分数的方式。若共有 $N$ 支有效队伍，某分项名次为 $r$，并列时取平均名次，其名次分为：

$$
\mathrm{RankScore}=100\times\frac{N-r}{N-1}.
$$

详细评分标准如下。

| 评分模块 | 权重 | 内部构成 | 计分方式 |
|---|---:|---|---|
| 构音障碍评估性能 | 60% | 隐藏测试集 Macro-F1 | 原始指标越高越好，按名次换算分数 |
| 模型效率 | 20% | 参数量 10；计算量 10 | 数值越小名次越高，分别换算后合成 |
| 技术报告 | 20% | 技术合理性、完整性、复现性与分析深度 | 教师直接评分 |

## 5. 客观指标与复现规则

本赛题使用五类 Macro-F1 作为唯一排名性能指标。令 $\mathrm{TP}_c$、$\mathrm{FP}_c$ 和 $\mathrm{FN}_c$ 分别表示类别 $c$ 的真阳性、假阳性和假阴性数，则

$$
F1_c=
\frac{\mathrm{TP}_c}
{\mathrm{TP}_c+\frac{1}{2}(\mathrm{FP}_c+\mathrm{FN}_c)}.
$$

最终 Macro-F1 为：

$$
\mathrm{Macro\!-\!F1}
=\frac{1}{5}\sum_{c=1}^{5}F1_c.
$$

Macro-F1 对每个类别赋予相同权重，适合训练类别不均衡的情形。课程组固定评价脚本、标签对齐方式与缺失预测处理规则；参赛队提交的本地结果仅供参考。

预测文件若缺失某位受试者、存在重复 ID、类别不在 1--5 范围内或无法读取，则该提交不进入正式排名，或由课程组按该受试者预测错误处理。

## 6. 参数量与计算量评分

本项目不设置硬性的参数量或 FLOPs/MACs 上限，但会按效率排名赋分。允许采用模型集成或外部预训练模块，其全部推理成本都必须纳入统计。

| 项目 | 统一口径 |
|---|---|
| 参数量 | 统计推理时加载的全部参数，包括冻结模块；多个模型按总和计。 |
| 计算量 | batch size = 1；输入为一名受试者的全部 8 条 8 kHz 语音；报告总 GMAC/subject。一次 MAC 按一次乘加计算。 |
| 复核 | 提交参数和计算量统计日志，以及一条可复现命令。 |

效率名次中，参数量和计算量分别从小到大排序。

## 7. 技术报告评分量规

| 维度 | 高分标准 |
|---|---|
| 技术合理性 | 特征或模型结构明确；多录音融合动机充分；与基线差异清楚。 |
| 完整性 | 覆盖数据、模型、训练、评测、效率、数据合规与复现信息。 |
| 分析深度 | 给出类别级结果和失败案例讨论。 |

### 7.1 推荐报告结构

- 摘要：任务、核心方法和主要结果；
- 数据：课程数据使用范围、外部资源、划分、清洗和增强策略；
- 方法：单条录音编码、多录音融合、元数据融合、分类头和损失函数；
- 实验：训练配置、公开验证集类别级 F1、混淆矩阵、消融实验和效率结果；
- 讨论：主要贡献、局限与后续方向。

### 8.1 预测文件格式

预测文件必须命名为 predictions.csv：

~~~csv
ID,Class
ID011,3
ID014,5
ID334,2
~~~

ID 必须与测试清单逐字一致；Class 必须是 1--5 的整数。输出顺序不限，但每位受试者必须恰好出现一次。

~~~text
team_<编号>/
├── README.md
├── requirements.txt
├── src/
├── scripts/
│   ├── train.py
│   ├── infer.py
~~~

README 必须给出一条可执行的盲测试推理命令，形式例如：

~~~bash
python scripts/infer.py \
  --audio-root <测试音频目录> \
  --metadata <测试清单.csv> \
  --output <输出目录>/predictions.csv
~~~

最终评测环境不连接互联网。任何推理时需要下载的模型权重、词表或其他资源，必须随提交包提供，或在 README 中明确为课程预装依赖。
